===== THE POSITION UNDER DEFENSE =====

The Phase-3 Bernoulli illustration in the mi-spectral manuscript's response to reviewer r3#2 is methodologically sound as executed, and no additional/different non-normal family is needed to answer r3#2 -- despite the fact that the target used to score Bernoulli's measured result was changed AFTER the data were seen.

BACKGROUND FACTS:
- The paper's central theorem predicts E[T] = +1/2*tr(RIV) for a deterministic FIML-style plug-in, whenever the model's own conditional missing-data entropy depends on the parameter being estimated (formally: alpha = -entropy-gradient != 0 at the true parameter). This is the GENERAL case, and it is the only case the paper's own applications (AIC/BIC/LRT correction, all multivariate-normal-with-estimated-covariance) actually use.
- The paper ALSO derives a narrower special-case identity: when a model has a SEPARATE, held-fixed scale/dispersion parameter and only a LOCATION parameter is estimated (e.g. a Gaussian mean under KNOWN variance), the model's entropy does NOT depend on the estimated parameter (alpha=0 exactly), and the bias COLLAPSES to 0 (deterministic plug-in) or -1/2*tr(RIV) (a genuine Bayesian posterior draw). This "known-scale collapse" is a boundary/edge-case result, verified so far only in the multivariate-normal family, and is NOT what the paper's applications use.
- Reviewer r3#2 wrote: "The manuscript relies exclusively on a four-dimensional multivariate normal distribution for all empirical validations... The authors should discuss how the derived trace penalty and design-imbalance terms are expected to behave under non-normal likelihoods, and whether the current findings can be safely generalized to standard GLM frameworks used in applied research." This names "categorical or skewed continuous variables commonly modeled via Generalized Linear Models" as the concrete worry.
- BEFORE any code ran, a registration document (todo/040 Sec.9) predicted: Gamma (has a separate shape/dispersion parameter; both mean and shape estimated) tests the GENERAL case, predicted +0.5*tr(RIV) FITTED / more-negative for a genuine Bayesian draw. Bernoulli (no separate dispersion parameter) was ALSO chosen before any code ran, but was predicted to test the KNOWN-SCALE COLLAPSE (predicted ~0 FITTED / ~-0.5 for a Bayesian draw), reasoning "Bernoulli has no explicit dispersion parameter, so it must be the known-scale case."
- Measured results (R=1000 repetitions, M=50 imputations each, bootstrap SE via a ratio-of-means estimator): Gamma FITTED = +0.318 (se 0.200) -- inside the 95% interval around +0.5, a clean confirmation of the GENERAL-case prediction. Bernoulli FITTED = +0.853 (se 0.161) -- about 5.3 se from the REGISTERED prediction of ~0, a clear pre-registered miss. Bernoulli's Bayesian draw (mice logreg) = +0.628 (se 0.161) -- about 7 se from the registered -0.5 prediction, and the WRONG SIGN relative to that prediction.
- AFTER seeing this miss, the advocate derived that Bernoulli's own entropy H(p) = -[p*log(p) + (1-p)*log(1-p)] has dH/dp = -logit(p), nonzero for any p != 1/2, meaning alpha != 0 for Bernoulli generically -- so Bernoulli does NOT instantiate the known-scale collapse at all (it cannot: it is a ONE-parameter exponential family with no separate location and scale parameters to begin with, unlike Gaussian, which has two separately-identifiable parameters, one of which CAN be held fixed). The advocate then re-scored Bernoulli against the GENERAL-case target instead: +0.853 vs the (new, post-hoc) target of +0.5 is about 2.2 se off -- same sign, same rough order of magnitude -- and the Bayesian draw (+0.628) IS more negative than the FITTED anchor (+0.853), matching the SAME directional Bayesian-draw-discount mechanism seen in Gamma and in the paper's earlier MVN data-augmentation-engine work.
- The human author (Marcus, corresponding author) objected that this looks like HARKing -- deriving a new target only after the original one failed, then claiming the new target was correct all along -- and asked for a rigorous, adversarial defense before accepting it.

DEFEND: (1) that choosing Bernoulli in the first place (before any code ran) satisfies both the letter and the intent of reviewer r3#2's request; (2) that switching the scoring target for Bernoulli from "~0, known-scale" to "+0.5, general-case" post-hoc is legitimate theory-correction (recognizing a misapplication of an ALREADY-EXISTING, already-derived theorem condition to a new instance) rather than HARKing, and that this does not require re-registering and re-running a DIFFERENT non-normal family (e.g. a genuine two-parameter known-scale exemplar like Student-t or Laplace with fixed scale) to legitimately close out r3#2.
